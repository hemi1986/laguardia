## Resolution (implementer, 2026-10-02)

Findings of this review (#) and of the acceptance test (`ST-060-acceptance.md`, AT):

- **#1 major – fixed.** The document no longer claims logging in works on the museum's domain only; it says `laguardia.vercel.app` still serves production and must not be handed out.

- **#5 – checked.** Vercel's environment variables hold no `BETTER_AUTH_URL` (names read only, 2026-10-02); recorded in the document.
- **#6 – fixed.** The scan matches `\.vercel\.app\b`, so built-up addresses count too; self-test with `` `https://${project}.vercel.app` ``.
