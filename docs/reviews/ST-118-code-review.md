**Security pass (no findings):**
- **SQL injection:** every searched word reaches SQL as a bound parameter (`${word}` inside Drizzle's `sql` template, also through `sql.join`). There is no `sql.raw`, and the `regconfig` and regex literals are constants. The `search` address parameter is never sent to SQL itself; only the words from `searchWordsOf` are, and they hold letters and digits only (NUL and control characters are separators).
- **Input:** the search is cut to 200 characters (`searchOf`) and rendered through React (`defaultValue`, hidden `value`), so it is encoded. `KNOWN` and `strictFileOverviewQueryOf` keep the details page's origin check exact: a search with spaces around it, or sent twice, is not a known origin (tested).
- **Authorization and data:** the page still runs only after the team page's access check. Nothing is logged. No internal IDs or staff names are added.
- **Query cost:** at most 8 words, so at most 8 AI queries on the GIN index plus one Collection query (see #2).
- **Migration:** `to_tsvector(regconfig, …)` and `regexp_replace` are immutable, so they are valid in a `STORED` generated column. Adding the column rewrites `ai_index_item` (embeddings included) under an exclusive lock, which is acceptable at museum size. I found no `select()` of whole `ai_index_item` rows that would now read the `tsvector`.
- **Module boundary:** `collection/file-overview.ts` names no AI and imports only Collection's schema. `files-containing-words.ts` joins only `ai_index_entry` and `ai_index_item`. The page (`file-overview-data.ts`, `search-order.ts`) merges by file ID in memory, which follows conventions *Reading across modules – the page composes* and the context map.
- **German and English matching otherwise:** „Spule“ finds „Spulen“, „coil“ finds „coils“, and „Plan“ does not find „Schaltplan“ (all checked locally). The only gap is the stop-word case in #1.

**Verdict:** ready to merge (no blockers; #1 should be fixed in this story).
Most important finding: #1 – a word that is a stop word in both German and English („in“, „an“, „am“) can never be found, so a natural search like „Relais in Backbox“ finds nothing.
