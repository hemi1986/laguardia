## Resolution (implementer, 2026-10-02)

Findings of this review (#), of the acceptance test (`ST-010-acceptance.md`, AT) and of the security review (SR):

- **#1 major – fixed.** The `Cache-Control` entry in `next.config.ts` was overridden (the preview sent Next.js's own `private, no-cache, no-store, max-age=0, must-revalidate`) – removed. The page comment and the conventions now name the real mechanism: the page reads the request (language; with ST-011 the session), so Next.js renders it per request and sends that header itself. The preview-only test stays the guard (green on the preview).
- **#6 – fixed.** The unknown-number page shows the language switch and a link to the start page (G17); browser test.
- **#7 – fixed.** `languageSwitch` is a section of its own in both visitor catalogues (the start page uses it too); the unused `machinePage.language` is gone.
- **#8 / SR – fixed.** The language switch goes back only to a same-site path: `sameSitePath` (`src/app/same-site-path.ts`) refuses `//`, a backslash after the leading slash, whitespace and control characters; table test.
- **#9 / AT (malformed percent sequence) – no change needed.** Next.js answers 400 for `/m/%E0%A4%A` before the page runs; a browser test pins it ("not a server error").
- **#2 – revisit with ST-068.** The cache test requests the unknown-number page because the preview has no machine; add a real machine when the preview is seeded.
- **#3 / AT R1 – accepted.** "Changes are visible immediately" tests the data loaded per request; a reload of the route after a status change needs ST-012's status change.
- **#4 / AT R2 – revisit with ST-013.** The browser test cannot create a problem report yet; the integration test proves the page's data loads no report text.
- **#5 – revisit with ST-013.** The rule "reporting only for a machine on display" sits in the page data for the button; ST-013's command enforces it and can give it one home.
- **AT (lowercase "lg-042") – skipped.** QR stickers carry the museum number as printed (upper case); no story asks for case-insensitive addresses.
- **AT (retired machine) – ST-055.** It shows the unknown-number page until ST-055 decides retired machines' visitor pages.
- **#10 – revisit at the next architecture review.** A `MuseumNumber` type – already planned with the museum number register in ST-035.
