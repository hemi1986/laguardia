**Bug-focused pass.** No defect found in the committed paths.
- The HS-37 guarantee holds under concurrency. The partial unique index on `(true) WHERE state = 'requested'` makes a racing second insert wait for the first and then fail with `23505`. That error becomes `Rejected("ai-model-proposal-being-written")` inside the transaction, which rolls back, and `executeCommand` returns it as a domain rejection, not a 500. The facts check runs first for the usual case.
- A malformed `proposalId` in the address returns `undefined` through `aggregateStore.load`'s `isId` guard, so the page shows "Diesen KI-Vorschlag gibt es nicht." instead of a database error.
- The form keeps the typed description after a rejection (`state.values`, `keptKey`). `whyNot` replaces the form only on first render, not after a rejection, so G8a holds.
- The decision uses the injected clock and ID generator. There is no `new Date()`.

**Security-focused pass.** No finding.
- Authorization is technicians only, at three layers: `requireTechnician()` on both pages and in the Server Action, and `allowedActors: ["technician"]` on the command. A helper or anonymous post is refused by the command layer even without the page check.
- CSRF is covered by Next.js Server Action origin checks, the same as every other form on the runner.
- Forged fields: the input function reads only `description`. Extra fields are ignored. `chatModel`, `requestedBy` and the ID come from the settings, the session and the generator, never from the form.
- The description is free text. It is trimmed, stored only on the aggregate, kept out of the journal (the test asserts this, `:634`), and rendered through React, so it is escaped. There is no `dangerouslySetInnerHTML`.
- Internal IDs appear only on team pages (the proposal address). There are no public pages and no logging of the description.

**Verdict:** ready to merge
Most important finding: #1. Until ST-124/ST-126 exist, a requested AI model proposal never leaves *requested*, so release ST-123 only together with them, or with AI off in production.
