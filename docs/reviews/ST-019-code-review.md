3. **Migration 0012** – correct. `COALESCE(… = 'resolved-on-the-spot', false)` makes the note NULL for untriaged reports and for every other outcome. Existing rows comply (no command produced this outcome before; `triageForTest` uses `dismissed`). Same pattern as `problem_report_triage_defect`.
4. **`triageOutcome` on `problemReportForTriage`** – fine. The confirmation is only shown for an ID that is stored as *resolved on the spot*, so the URL can't make the page claim something that isn't stored. Duplication with the ST-018 confirmation: finding 4.
