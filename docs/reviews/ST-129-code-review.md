# Code review – ST-129: The chosen links of a saved proposal are loaded as files
Base: main · Commits: 3 · Date: 2026-11-07

Scope of this pass: the story's diff, plus (1) a bug-focused pass over the command layer's `run(…, { as })`, and
(2) a security-focused pass over the web-fetch seam (`src/platform/web-fetch/*`) and over
`proposed-document-work.ts` / `proposed-document-content.ts`. Decision already taken by the main session and not
re-opened here: the file is added on behalf of `state.requestedBy` with role `technician`.

Checked by running code (scratchpad scripts, nothing committed): the real adapter with its real DNS lookup refuses
`https://localhost.localdomain:9/…` and `https://127.0.0.1.nip.io:9/…` (`address-not-allowed`) and fetches
`https://example.com/`. `allowedWebAddress` refuses `0x7f.1`, `2130706433` and `[::ffff:7f00:1]`. `textOfWebPage` is
quadratic on malformed markup (see #1). The story's unit tests pass (86 tests in 7 files).

Language check: the new warnings in the story's files (`link`, `chunk` for HTTP body chunks in platform code, `BLOCKS`)
are false positives. *Link* is the term of `events.yaml` and the story, and *chunk* there is not an AI index passage. The
UI words „nicht erreichbar“, „zu groß“, „kein PDF oder Text“, „Adresse nicht erlaubt“, „abgebrochen“ and „Wird geladen …“
match the story. Architecture otherwise as the ADRs say:
- The fetch happens outside any transaction, and one short transaction ends the hold (ADR 0015).
- CMD-LoadProposedDocument is the system's and calls Collection's CMD-AddFile in the same transaction through `run` (ADR 0002, 0019).
- The events carry the IDs from `events.yaml` and only references (index, file ID, reason).
- Nothing personal is logged, and the content is never executed. A page's scripts and styles are dropped, and the text is stored as `text/plain`.
- The redirects are followed by hand: every hop is checked, with at most five redirects, a 60 s timeout, and the declared and the streamed size both limited.

Verdict: ready to merge (no blockers). The three majors #1–#3 should still be fixed in this story.
Most important finding: #1. The HTML-to-text pass is quadratic on malformed markup, so one ticked web page can block the background run's event loop for minutes to days.

## Resolution (main session)

Fixed in this story: #1 (`textOfWebPage` is now one linear scan; test with hostile pages and a time limit), #2 (`recorded` is set
only after `storeResult` resolved), #3 (new test: a fetch outliving its hold records nothing and leaves no content), #7 (all
trailing dots of a host are stripped), #8 (text and Markdown are stored as UTF-8 whatever charset was declared), #11 (`role="alert"` dropped).
Skipped: #4 (the lookup is a thin wrapper around `dns.lookup` and `isPublicIp`, both tested; a real-DNS test would need the network),
#5 (`policies` never carry `as`), #6 (design decision: the requester, role technician), #9 (same convention as
`CreateMachineModelInput.id`), #10 (the write keeps https links only, the SQL update stands in for an older shape), #12 (a handful of waiting links).
