## Checked and in order

- **ADR 0002 / command layer:** `changeFileDetailsCommand` is an `aggregateCommand` on AGG-File, with authorization through `changingActors` and the event journaled in the same transaction. The app imports only `@/modules/collection` (its index). The decision is pure: no clock, no `new Date()`. `mayChangeNothing: true` follows HS-27/ST-100: unchanged → no event, version stays, no conflict, as conventions.md:722 says. The removed-file check comes before the input rules, so the domain rejection wins (Q11).
- **IDs:** CMD-ChangeFileDetails and EVT-FileDetailsChanged come from `events.yaml`. All 9 scenario titles are present exactly.
- **Domain rules:** title required (trimmed) and exactly one file category (forged values → `file-category-required`) are enforced in the aggregate through `addFileRefusal`. The original file name and the content cannot be changed. A removed file → `file-removed`. A real attach or detach raises the version, as the data model wants.
- **Journal:** `changedDetails` and `fileCategory` only. The typed title stays out, and the test checks that (`not.toContain("Operations")`). The actor is the journal's actor.
- **Language:** Datei bearbeiten, Titel, Dateikategorie (Handbuch / Schaltplan / Foto / Sonstiges), Datei speichern, Zurück zur Datei – all from the story and the `_UI (de)_` lines. No `_Avoid_` words in new names.
- **Scope:** nothing beyond the story. No AI work: the test checks there is no run, no OpenRouter request and the index entry is unchanged.

## Security pass

- **Origin (`from`):** the closed set from `originOf`, checked on the form page and again on the landing page. The bound value is `originValue(file.origin)` of the checked origin. It is encoded through `URLSearchParams` into a fixed path, so there is no open redirect, even with a forged bound argument.
- **`saved=1`:** a flag only. The confirmation text is the file's current title from the database, never from the URL, so nothing is reflected. A hand-typed `?saved=1` shows a harmless "gespeichert", like the `?saved=ai` precedent (conventions.md:413).
- **Title:** rendered as React text (escaped), kept out of the journal and logs. There is no maximum length, which is deliberately not raised.
- **Version:** `versionSeen` makes anything that is not a whole number a version nobody saw. An unchanged send with a stale version lands without a conflict by design (HS-27), because nothing is written.
- **CSRF / session:** the POST goes to a page, so the proxy checks the Origin. The action calls `requireTeamMember()` and the runner takes the actor only from `currentPerson()`.
- **Removed file:** the form page of a removed file shows its title in the heading and offers no save. This matches the ST-121 removal page. The data model keeps the title for earlier references, and the page is team-only. Accepted.
- **Open:** finding 4 (a non-UUID bound `fileId` gives a 500).

No finding meets the follow-up hurdle for a new story.
