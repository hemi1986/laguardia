Most important: #1 – the grace period after a return is computed from the interval starting on the return date. The scenario cannot tell this reading apart from the other one, so state it explicitly (doc comment, or `[OPEN]` if unsure).

## Disposition (`/implement`, 2026-10-15)

- **#1 fixed** – the doc comment of `dueAfterReturn` says the grace days count over the interval *starting on the return*: the time convention's `graceDays(start, months)` was built for that start (ST-003, engineering conventions: "grace days from any start (e.g. the return to display, ST-056)"). Not open – the time convention decided it.
- **#2 fixed** – `NOT_ON_DISPLAY: MachineStatus` as a bound parameter in the subquery.
- **#3 fixed** – `CONTEXT.md` *Due / Overdue* states the return rule in one sentence.
- **#4 fixed** – `machineForMaintenance` carries the location; the form page no longer loads every machine.
