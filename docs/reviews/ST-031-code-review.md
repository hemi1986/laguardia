- #2 fixed – `Released claim of (optional)` in the data of EVT-DefectDetailsChanged in `events.yaml`, and in the journal-only paragraph of `data-model.md`.
- #6 fixed – the scenario test asserts the version (1 → 2), so the release is in the same step as the change.
- #3 skipped – revisit in the next `/improve-codebase-architecture` (how `lastDefectActionBy` grows per action); `releasedClaimOf` stays, the confirmation needs it on the step's last entry.
- #4 skipped – the form shows the defect's current values and a hint about the claim; sharing `DefectFields` would mean a variant for one checkbox and one input – revisit if a third form needs them.
- #5 skipped – the refusal per command is the convention ("each command's own rule"); two identical bodies are two rules that may diverge.
