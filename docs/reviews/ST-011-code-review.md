## Resolution (implementer, 2026-10-03)

Findings of this review (#), of the acceptance test (`ST-011-acceptance.md`, AT) and of the security review (SR – no findings):

- **#1 major – fixed.** "Bitte mindestens ein Gerät auswählen." is rendered inside the choice form, right above its button (G8); the search term travels with the form and comes back with the redirect. Browser test asserts the alert inside the form.
- **#2 major – fixed.** The print page has "Zurück zur Auswahl" next to "Drucken" (`print:hidden`), keeping the search (G17); browser test follows it.
- **#3 major – fixed.** The unit test is titled "shows the QR code, the museum number and the prompt …"; `ST-011: Technician prints a QR sticker` is the browser test only.
- **Count on load – fixed.** The live count counts the ticked boxes once the page is interactive (the browser may restore them).
- **Empty choice – fixed.** Without any active machine the page says "Noch kein Gerät erfasst." instead of an empty form (G7).
- **@page / AT 2 – fixed.** A4 without margins applies only to sticker pages (named page `stickers`); no page break after the last sheet, so no blank trailing page.
- **e2e `openMore` that checked nothing – removed.**
- **Re-search loses ticked boxes – skipped.** Search, then tick, then print is the flow; revisit if the museum prints for many machines in several searches.
- **`machinesToPrintFor` pass-through / the print page importing from `(team)` – skipped.** One caller each; revisit when a second printable page appears.
- **The English prompt in the team catalogue – skipped.** The sticker is a team-printed object that carries both languages at once; the visitor catalogues are per language.
- **Print preview wider than 360 px – accepted.** The page is an A4 sheet (210 mm) by nature; the choice page stays within 360 px.
- **Cache scenario on the preview – covered by ST-010's preview test** for `/m/`; the redirect for a team member is rendered per request the same way.
- **AT 2 / AT 5 – for the user before the first real print:** one test print on plain A4 held against an L7160 sheet, and confirming the domain (`QR_DOMAIN`, provisional).
