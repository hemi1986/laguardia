Base: main · Commits: 8 · Date: 2026-10-18

What is sound: the command goes through `aggregateCommand` with a version check and `context.run` for Collection's CMD-ChangeMachineStatus (as in ST-018). The helper/technician split is enforced in the decision (`not-authorized`) and hidden on the form (G11). Every scenario has an exactly titled test at an agreed seam.
