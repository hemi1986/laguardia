## Resolution (/implement, 2026-10-31)
- #1 fixed – `e2e/legal-pages.spec.ts` checks the page's title and a non-empty museum text instead of placeholder sentences (the placeholder itself is covered by "ST-103: Before any change the placeholder privacy notice is shown").
- #2 partly fixed – the `reference` rule is off, so a reference definition and a reference link or image stay their source (tests added). Skipped minor: decoded entities, indented code losing its indentation and a link's title attribute – none is an element outside the allowed set, none is unsafe.
- #3 fixed – the conventions say why the image rule is wrapped, not disabled.
- #4 fixed – markdown-it pinned to `~15.0.3`.
- #5 fixed – "imprint provided" derived once (`imprintProvided(db)` from the stored legal texts); `MuseumSettings` no longer carries it, `welcomePage` asks it.
- #6 skipped minor – a `no-restricted-imports` entry would have to be repeated in the `src/app` block, which overrides the rule per file, and then lifted again for `legal-markdown.tsx`; `react/no-danger` already guards the only way rendered HTML reaches a page. Revisit when a second Markdown use appears.
- #7 fixed – the typed text gets an https and a mailto link, and the test asserts exactly those two addresses survive.
- #8 skipped minor – `LegalText` as a branded type adds nothing the decision's normalisation doesn't already guarantee.
